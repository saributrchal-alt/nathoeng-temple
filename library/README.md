# ห้องสมุดวัดนาเทิง · library.nathoeng.com

เว็บไซต์ห้องสมุดแยกเป็น Vercel Project ของตนเอง โดยชี้ Root Directory มาที่ `library` ใน GitHub repository เดียวกับเว็บวัด ใช้ฐานข้อมูล Supabase ชุดเดิมเพื่อให้สมาชิกและบัตรสมาชิกเลข 13 หลักของวัดใช้กับห้องสมุดได้ทันที ไม่ต้องสมัครซ้ำ เว็บวัดยังคงมี Serverless Functions 12 ไฟล์ ห้องสมุดมี `library/api/library.js` หนึ่งไฟล์ในโปรเจกต์ใหม่

## เตรียมใช้งาน

1. เปิดไฟล์ [`../supabase/library-portal.sql`](../supabase/library-portal.sql) ทั้งไฟล์ใน SQL Editor ของ Supabase **โปรเจกต์เดิมของวัด** แล้วกด Run หลังจากมีตาราง `members` และ `member_card_numbers` แล้ว หากตารางบัตรสมาชิกยังไม่พร้อม ให้รัน `supabase/member-card-numbers.sql` ก่อน
2. ใน Vercel สร้าง **โปรเจกต์ใหม่** จาก GitHub repository `saributrchal-alt/nathoeng-temple` และกำหนด Root Directory เป็น `library` (ไม่เพิ่ม Root Directory นี้ใน Vercel Project ของเว็บวัด) เลือก Vite หาก Vercel ไม่รู้จักเฟรมเวิร์กเอง Build Command คือ `npm run build`; Output Directory คือ `dist`
3. ตั้ง Environment Variables ใน **โปรเจกต์ห้องสมุดใหม่**: `SUPABASE_URL` และ `SUPABASE_SECRET_KEY` ใช้ค่าของโปรเจกต์เว็บวัด; `LIBRARY_SESSION_SECRET` เป็นค่าสุ่มลับใหม่ ยาวอย่างน้อย 32 ตัวอักษร เก็บไว้ฝั่งเซิร์ฟเวอร์เท่านั้น ห้ามใช้ค่า public หรือใส่ค่านี้ใน `VITE_*`
4. เพิ่มโดเมน `library.nathoeng.com` ให้โปรเจกต์ห้องสมุดใน Vercel แล้วตั้ง DNS ให้ตรงกับค่าที่ Vercel แสดง เช็กว่า HTTPS เข้าได้ ปรับ Environment Variables / DNS แล้ว Redeploy หากจำเป็น
5. ให้ Admin ของวัดเข้าสู่ระบบที่ `watt.nathoeng.com` จากนั้นกด "เข้าสู่ระบบสมาชิกวัด" บนเว็บห้องสมุด เพื่อตรวจการเชื่อมบัญชี และที่เมนู "โต๊ะบรรณารักษ์" สามารถสแกนบัตรสมาชิกเพื่อมอบสิทธิ์บรรณารักษ์ได้

**ลำดับสำคัญ:** รัน SQL ก่อนเปิดใช้งานเว็บห้องสมุดบนโดเมนจริง ระบบเข้าสู่ระบบจะส่งตั๋วใช้ครั้งเดียวอายุ 2 นาทีจากเว็บวัดมายังห้องสมุด และตั้งคุกกี้แยกสำหรับห้องสมุด สมาชิกที่ถูกยกเลิกจะเข้าใช้งานไม่ได้ บัตรสมาชิกใช้ระบุตัวตนที่โต๊ะโดยเจ้าหน้าที่ ไม่ใช้เลขบัตรเป็นรหัสผ่านเข้าสู่ระบบจากระยะไกล

## วิธีใช้งาน

- ผู้มาเยือนค้นหาชื่อหนังสือ ผู้แต่ง หัวข้อ หรือ ISBN จากช่องค้นหาเดียว แล้วกดดูรายละเอียดหนังสือ สมาชิกวัดล็อกอินด้วย LINE, Telegram หรือชื่อผู้ใช้/รหัสผ่านเดิมของวัด เลือกได้สูงสุด 5 ชื่อหนังสือต่อคำขอ
- ผู้ยืมเลือกมารับเองที่วัด หรือให้จัดส่งโดยชำระค่าส่งขาไปปลายทาง กรอกชื่อ โทรศัพท์ ที่อยู่ และรหัสไปรษณีย์เมื่อเลือกจัดส่ง แล้วกดยอมรับเงื่อนไขด้วยตนเองก่อนยื่นคำขอ
- เจ้าหน้าที่รับคำขอใน "โต๊ะบรรณารักษ์" (รายการรีเฟรชทุก 30 วินาที หรือกดอัปเดตเอง) ตรวจและกำหนดวันคืน การอนุมัติจะจัดสรรเล่มจริงจากชั้นวาง หากหนังสือไม่พอ ระบบแจ้งให้แก้ไข เจ้าหน้าที่กดพร้อมรับหรือพิมพ์ฉลากและกรอกเลขพัสดุขาไป
- ผู้ยืมกดยืนยันได้รับหนังสือ แล้วเมื่อจะคืน เลือกนำมาคืนเองหรือส่งพัสดุพร้อมเลขติดตาม เจ้าหน้าที่กดยืนยันรับคืนเพื่อปิดรายการและคืนสถานะหนังสือให้ยืมได้อีกครั้ง
- หากผู้ยืมไม่มีโทรศัพท์ เจ้าหน้าที่สแกนบัตรสมาชิกที่แท็บ "ตรวจบัตรสมาชิก" แล้วเลือก "เลือกหนังสือให้สมาชิกท่านนี้" พาเจ้าตัวดูและกดยอมรับเงื่อนไขบนหน้าจอที่โต๊ะ ระบบบันทึกคำขอในบัญชีสมาชิกคนนั้น และเจ้าหน้าที่ดำเนินการอนุมัติในคิวเดียวกัน
- เจ้าหน้าที่สแกน ISBN-13 ที่ขึ้นต้นด้วย 978/979 หลังหนังสือในแท็บ "รับเข้าหนังสือ" ระบบค้นข้อมูลจาก Google Books และ Open Library เท่าที่มีให้ ตรวจทานหรือกรอกเพิ่มก่อนบันทึก แต่ละเล่มมีรหัสสำเนา `LIB-...` แยกกัน

## ตรวจสอบก่อนเผยแพร่

ที่โฟลเดอร์หลักรัน `npm run build`, `npm run lint -- --quiet` และ `node --test library/test/*.test.mjs`; ที่โฟลเดอร์ `library` รัน `npm run build` หลังติดตั้ง dependencies เมื่อทั้งสองโปรเจกต์ใช้ Vercel แล้วทดสอบคำขอจริงด้วยสมาชิกตัวอย่างหนึ่งบัญชีตั้งแต่กดยืมจนถึงกดรับคืน ไม่ต้องใส่ข้อมูลบัตรประชาชนในช่อง ISBN หรือบัตรสมาชิก

ระบบบันทึกเลขพัสดุ แต่ยังไม่ได้ดึงสถานะขนส่งโดยตรงจาก API ของบริษัทขนส่ง บรรณารักษ์และผู้ยืมเปลี่ยนสถานะเองตามการส่งมอบจริง
