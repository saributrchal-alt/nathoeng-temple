# ผู้ดูแลแก้ไขโปรไฟล์สมาชิก

## ดำเนินการในนามสมาชิก

ในเมนู **สมาชิก** เลือกบัญชีสมาชิกทั่วไปแล้วกด **เข้าใช้งานในนามสมาชิก** ระบบเปิดหน้า **บัญชีของฉัน** ของสมาชิก พร้อมแถบสีเหลืองแจ้งชื่อสมาชิกและปุ่ม **กลับบัญชี Admin** ที่ด้านบน Admin ดูประวัติและบันทึกการบริจาคแทนสมาชิกได้ รายการบริจาคจะเก็บสมาชิกเป็นเจ้าของและเก็บรหัส Admin ในช่องผู้บันทึก

โหมดนี้อยู่ได้สูงสุด 4 ชั่วโมง บัญชี Admin เปลี่ยนรหัสผ่าน แก้โปรไฟล์ เชื่อม LINE/Telegram สมัคร Push หรือยกเลิกสมาชิกจากโหมดนี้ไม่ได้ ให้ใช้เมนู Admin สำหรับการแก้ไขบัญชี ผู้ดูแลกลับบัญชีตนเองได้โดยไม่ต้องใช้รหัสผ่านของสมาชิก ไม่ต้องรัน SQL เพิ่มและไม่เพิ่ม Serverless Function

ปุ่ม **เข้าใช้งานในนามสมาชิก** แสดงในโปรไฟล์สมาชิกทั่วไปและโปรไฟล์ของผู้ดูแลระบบที่กำลังเข้าสู่ระบบเอง ผู้ดูแลเปิดมุมสมาชิกของตนเพื่อดูข้อมูลและทำรายการได้ โดยยังมีปุ่มกลับบัญชี Admin และไม่สามารถเปิดมุมสมาชิกของผู้ดูแลระบบคนอื่น

## ติดตั้งก่อนเปิดใช้

รัน `supabase/admin-edit-members.sql` ใน SQL Editor ของ Supabase โปรเจกต์วัด หลังจาก `supabase/walkin-members.sql` ที่ใช้กับระบบ Walk-in Registration แล้ว จึงนำโค้ดเว็บรุ่นนี้ขึ้น Production

SQL เพิ่มฟังก์ชันสำหรับบันทึกข้อมูลสมาชิก ชื่อผู้ใช้ และรหัสผ่านในธุรกรรมเดียว ไม่เพิ่มตารางหรือ Serverless Function ใหม่

หากหน้าแก้ไขแจ้งว่าโหลดโปรไฟล์ไม่สำเร็จ ให้รัน `supabase/password-credentials-permissions.sql` เพื่อให้คีย์ฝั่งเซิร์ฟเวอร์อ่านและแก้ตารางบัญชีรหัสผ่านได้ โดยไม่เปิดสิทธิ์แก่ผู้เข้าชมเว็บ ผลลัพธ์ท้าย SQL ต้องเป็น `server_can_read = true` และ `server_can_update = true`

## วิธีใช้

1. เข้าระบบด้วยบัญชี admin และเปิดเมนู **สมาชิก**
   - ในส่วน **ค้นหาสมาชิกด้วยบัตรประชาชน** เลือกไฟล์ `.json` จากเครื่องอ่านบัตร หรือกรอกเลข 13 หลักและกด Enter ระบบค้นหาบัญชีที่ผูกกับเลขบัตรแล้วแสดงปุ่มเปิดข้อมูลสมาชิก โดยไม่บันทึกหรือเปลี่ยนโปรไฟล์
   - หากเลขบัตรยังไม่ผูกบัญชี แต่ชื่อในไฟล์ตรงกับสมาชิกเดิม ระบบจะแสดงบัญชีที่อาจตรงกันให้เจ้าหน้าที่ตรวจสอบตัวบุคคลก่อนเปิดโปรไฟล์ หากยังไม่พบให้ค้นด้วยชื่อในรายการสมาชิก แล้วค่อยนำเข้าบัตรในหน้าแก้ไขโปรไฟล์
2. เลือกสมาชิกคนใดก็ได้ แล้วกด **แก้ไขโปรไฟล์ / ชื่อผู้ใช้ / รหัสผ่าน**
3. ถ้ามีไฟล์จาก Card Reader ของสมาชิกที่สมัครผ่าน LINE หรือ Telegram อยู่แล้ว ให้เลือกไฟล์ `.json` ในช่อง **นำเข้า Card Reader เพื่ออัปเดตสมาชิกเดิม** ระบบจะตรวจเลขบัตรกับบัญชีอื่นก่อนเติมชื่อ เลข 13 หลัก วันเกิด และรูปลงในฟอร์ม จากนั้นตรวจทานกับเจ้าของบัตร กดยืนยัน แล้วจึงกดบันทึก การนำเข้าไฟล์อย่างเดียวยังไม่เปลี่ยนข้อมูลในฐานข้อมูล
4. แก้ชื่อ เลขประจำตัวประชาชน/พาสปอร์ต วันเกิด ประเทศ และรูป โดยเลือกรูปจากเครื่องหรือกล้องแล้วเลื่อน/ซูมได้
5. ตั้งหรือแก้ชื่อผู้ใช้ได้ทุกบัญชี ทั้งสมาชิกที่สมัครที่วัดและสมาชิก LINE/Telegram หากบัญชียังไม่มีชื่อผู้ใช้ ต้องตั้งรหัสผ่านใหม่พร้อมกัน
6. กรอกรหัสผ่านใหม่อย่างน้อย 12 ตัวอักษรเมื่อต้องการตั้ง/รีเซ็ต หากเว้นว่างจะคงรหัสเดิม (ระบบไม่แสดงรหัสเดิม)
7. กด **บันทึกโปรไฟล์และบัญชี**; เมื่อเปลี่ยนรหัสผ่าน ระบบแสดงรหัสใหม่ให้เจ้าหน้าที่แจ้งเจ้าของบัญชีโดยตรงหนึ่งครั้ง แล้วกด **ซ่อนรหัส**

การเปลี่ยนชื่อผู้ใช้หรือรหัสผ่านไม่ตัดการเชื่อมบัญชี LINE/Telegram การแก้โปรไฟล์และรหัสผ่านถูกบันทึกในตาราง audit เดิม บัญชีที่ลงชื่อเข้าใช้อยู่แล้วจะคง session เดิมจนออกจากระบบหรือหมดอายุ; รหัสใหม่มีผลกับการเข้าระบบครั้งถัดไป
