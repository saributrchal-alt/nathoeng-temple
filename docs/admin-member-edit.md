# ผู้ดูแลแก้ไขโปรไฟล์สมาชิก

## ติดตั้งก่อนเปิดใช้

รัน `supabase/admin-edit-members.sql` ใน SQL Editor ของ Supabase โปรเจกต์วัด หลังจาก `supabase/walkin-members.sql` ที่ใช้กับระบบ Walk-in Registration แล้ว จึงนำโค้ดเว็บรุ่นนี้ขึ้น Production

SQL เพิ่มฟังก์ชันสำหรับบันทึกข้อมูลสมาชิก ชื่อผู้ใช้ และรหัสผ่านในธุรกรรมเดียว ไม่เพิ่มตารางหรือ Serverless Function ใหม่

## วิธีใช้

1. เข้าระบบด้วยบัญชี admin และเปิดเมนู **สมาชิก**
2. เลือกสมาชิกคนใดก็ได้ แล้วกด **แก้ไขโปรไฟล์ / ชื่อผู้ใช้ / รหัสผ่าน**
3. แก้ชื่อ เลขประจำตัวประชาชน/พาสปอร์ต วันเกิด ประเทศ และรูป โดยเลือกรูปจากเครื่องหรือกล้องแล้วเลื่อน/ซูมได้
4. ตั้งหรือแก้ชื่อผู้ใช้ได้ทุกบัญชี ทั้งสมาชิกที่สมัครที่วัดและสมาชิก LINE/Telegram หากบัญชียังไม่มีชื่อผู้ใช้ ต้องตั้งรหัสผ่านใหม่พร้อมกัน
5. กรอกรหัสผ่านใหม่อย่างน้อย 12 ตัวอักษรเมื่อต้องการตั้ง/รีเซ็ต หากเว้นว่างจะคงรหัสเดิม (ระบบไม่แสดงรหัสเดิม)
6. กด **บันทึกโปรไฟล์และบัญชี**; เมื่อเปลี่ยนรหัสผ่าน ระบบแสดงรหัสใหม่ให้เจ้าหน้าที่แจ้งเจ้าของบัญชีโดยตรงหนึ่งครั้ง แล้วกด **ซ่อนรหัส**

การเปลี่ยนชื่อผู้ใช้หรือรหัสผ่านไม่ตัดการเชื่อมบัญชี LINE/Telegram การแก้โปรไฟล์และรหัสผ่านถูกบันทึกในตาราง audit เดิม บัญชีที่ลงชื่อเข้าใช้อยู่แล้วจะคง session เดิมจนออกจากระบบหรือหมดอายุ; รหัสใหม่มีผลกับการเข้าระบบครั้งถัดไป
