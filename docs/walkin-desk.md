# โต๊ะงานบุญ: สมัครสมาชิกและบันทึกผู้บริจาค

## เตรียมระบบก่อนเปิดใช้

1. ตรวจเลขบัตรที่บันทึกซ้ำในฐานข้อมูลก่อน:

   ```sql
   select tax_id, count(*), array_agg(id::text) as member_ids
   from public.members
   where tax_id ~ '^[0-9]{13}$'
   group by tax_id having count(*) > 1;
   ```

   แก้ข้อมูลซ้ำให้เหลือคนละหนึ่งบัญชีโดยตรวจประวัติการทำบุญและการเข้าพักก่อน มิฉะนั้น unique index จะสร้างไม่สำเร็จ

2. รัน `supabase/walkin-members.sql` ใน SQL Editor ของ Supabase โปรเจกต์วัด แล้วจึงนำโค้ดเว็บขึ้นใช้งาน เพราะหน้าเข้าสู่ระบบเดิมจะอ่านคอลัมน์รูปโปรไฟล์ใหม่
3. ใช้บัญชีผู้ดูแลระบบที่มีสิทธิ์ `admin` เข้าหน้า **สมาชิก → ลงทะเบียนสมาชิกที่โต๊ะงานบุญ**
4. ทดสอบกับไฟล์จริงที่ส่งออกจากแอปอ่านบัตรแบบเดียวกับแอปเครือญาติ (`saributr-card-v1`, รุ่น 1.4 ขึ้นไป) รวมทั้งทดสอบผ่านคอมและมือถือที่โต๊ะงาน

## ระหว่างงานบุญ

- ผู้มีโทรศัพท์เข้าระบบสมาชิกเดิมและทำรายการได้ตามปกติ
- สำหรับผู้ไม่มีโทรศัพท์ เจ้าหน้าที่นำเข้าไฟล์บัตร `.json` ที่โปรแกรมอ่านบัตรบันทึก หรือกรอกข้อมูลเอง ระบบตรวจเลข 13 หลักกับสมาชิกเดิมก่อนสร้างบัญชีใหม่
- ตรวจชื่อ วันเกิด และรูปกับเจ้าของข้อมูล เลื่อนหรือซูมรูปในกรอบวงกลมแล้วกดใช้รูป โปรแกรมบีบอัดเป็น JPEG ขนาด 256 × 256 พิกเซล
- เจ้าหน้าที่กำหนดชื่อผู้ใช้และรหัสผ่านอย่างน้อย 12 ตัวอักษรให้สมาชิกใหม่ ไม่ต้องใช้ LINE หรืออีเมล แจ้งรหัสผ่านให้เจ้าของบัญชีโดยตรงและลบจากหน้าจอด้วยปุ่ม **คนถัดไป**
- กด **ไปบันทึกรายการทำบุญ** เพื่อเปิดฟอร์มที่ผูกผู้บริจาคกับ Member ID เดียวกัน ประวัติจะแสดงในบัญชีสมาชิกได้ในภายหลัง
- สมาชิกสามารถเข้าสู่ระบบด้วยชื่อผู้ใช้และรหัสผ่าน เปลี่ยนรหัสผ่าน และแก้ไขวันเกิด เลขประจำตัวประชาชน/พาสปอร์ต หรือรูปโปรไฟล์ได้ในบัญชีของฉัน

## ขอบเขตการทดสอบ

- Build เว็บและทดสอบ API ด้วยการจำลองฐานข้อมูลแล้ว การรัน SQL กับ Supabase จริง การเสียบบัตรจริง และการทดสอบการเชื่อมบัญชี LINE/Telegram กับสมาชิกที่สมัครหน้าโต๊ะยังต้องทำก่อนเผยแพร่สู่ production
- แอปอ่านบัตรเป็นตัวอ่านอุปกรณ์และส่งออกไฟล์ เว็บวัดรับไฟล์ดังกล่าวเพื่อใช้ได้ทั้งบนคอมและมือถือที่เข้าถึงไฟล์ ไม่ได้สั่งงาน USB reader จากเบราว์เซอร์โดยตรง
- ระบบบันทึกเฉพาะข้อมูลที่เจ้าหน้าที่ตรวจทาน ไม่เก็บไฟล์ JSON ต้นฉบับบนเซิร์ฟเวอร์ เลขบัตรจะไม่แสดงกลับในหน้ารายชื่อสมาชิก
