# เจ้าหน้าที่งานกฐินจากรายชื่อสมาชิก

ผู้ดูแลวัดเปิด Admin → สมาชิก → เลือกสมาชิก → มอบหมายฝ่ายงาน → เจ้าหน้าที่งานกฐิน (Staff) → ส่งไปเป็น Staff งานกฐิน ใช้ช่องมอบหมายเดียวกับฝ่ายบัญชี โดยตัวเลือกผู้ทำรายการ/ผู้ตรวจของฝ่ายบัญชียังคงเดิม

ระบบบันทึกสิทธิ์เฉพาะกฐินลงตาราง `kathin_drink_staff` เดิมในฐานสมาชิกที่ใช้ร่วมกัน เก็บ `assigned_by` จากบัญชีผู้ดูแลที่ลงชื่อเข้าใช้ ไม่เปลี่ยน `members.role` เป็น admin และไม่ส่งข้อความ LINE ให้สมาชิก

สมาชิกที่ได้รับสิทธิ์เห็นปุ่ม “แดชบอร์ดเจ้าหน้าที่งานกฐิน” ในบัญชีของฉัน กดเข้า kathin.nathoeng.com ผ่านสะพานบัญชีเดิม เพื่อดูยอดคิวรอ/เรียกแล้ว/ส่งแล้ว ช่วยสั่งให้สมาชิก เพิ่มสิทธิ์เครื่องดื่ม เรียกหรือเรียกซ้ำ และส่งเครื่องดื่ม

ถอนสิทธิ์ได้ในช่องมอบหมายเดิม สถานะในรายการเปลี่ยนหลังบันทึกสำเร็จ API กฐินตรวจสิทธิ์และสถานะสมาชิกจากฐานข้อมูลทุกคำขอ จึงปฏิเสธคำขอ staff หลังถอนแม้ cookie เดิมยังไม่หมดอายุ ส่วนเมนูเครื่องดื่ม เปิด/ปิดงาน และการมอบหมาย staff ยังเป็นสิทธิ์ Admin

ไม่มี SQL หรือค่าตั้งต้นใหม่สำหรับระบบที่รันตารางกฐินและ `kathin-service-permissions.sql` แล้ว หากฐานข้อมูลบันทึกสิทธิ์ไม่ได้ API แจ้งข้อผิดพลาดโดยไม่แสดงว่าส่งสำเร็จ

ชุดทดสอบใช้ข้อมูลสังเคราะห์ ตรวจมอบ/ถอนสิทธิ์ ผู้ดูแลที่หมดสิทธิ์ สมาชิกยกเลิก callback บัญชีของตนเอง และการส่งฝ่ายบัญชีเดิม ไม่มอบหรือถอนสิทธิ์สมาชิกจริงระหว่างทดสอบ
