# บัตรสมาชิกวัด

สมาชิกเปิด **บัญชีของฉัน → บัตรสมาชิกวัด** เพื่อแสดงบัตรบนมือถือหรือกด **พิมพ์บัตร** เจ้าหน้าที่เปิด **Admin → สมาชิก → เลือกสมาชิก → บัตรสมาชิกวัด** แล้วพิมพ์ให้สมาชิกที่ไม่มีมือถือได้ ขนาดพิมพ์ 85.6 × 54 มม.

ก่อนใช้งานบัตรแบบสแกน ให้รัน [member-card-numbers.sql](../supabase/member-card-numbers.sql) ใน Supabase SQL Editor หนึ่งครั้ง ระบบจะออกหมายเลข 13 หลักให้สมาชิกแต่ละคนเมื่อเปิดบัตรครั้งแรก หมายเลขไม่ซ้ำและไม่เปลี่ยนแม้แก้ไขโปรไฟล์ เลขนี้ **ไม่ใช่เลขบัตรประชาชน**

บัตรแสดงชื่อ รูปโปรไฟล์ หมายเลขสมาชิก 13 หลัก และบาร์โค้ดเส้น EAN-13 ขนาดใหญ่พร้อมหลักตรวจสอบสำหรับเครื่องอ่านบาร์โค้ดแบบเลเซอร์ หากไม่มีรูปจะแสดงสัญลักษณ์วัด เจ้าหน้าที่ไปที่ **Admin → สมาชิก → สแกนบาร์โค้ดบัตรสมาชิก** กด **เริ่มสแกน** แล้วสแกนได้เลย ระบบค้นหาเมื่อรับเลขครบ 13 หลักหรือเครื่องส่ง Enter จากนั้นกด **เปิดข้อมูลสมาชิก** เพื่อดูโปรไฟล์ หากไม่มีเครื่องสแกนสามารถกรอกเลขใต้บาร์โค้ดและกดค้นหาได้ ช่องนี้แยกจากช่องเลขบัตรประชาชน 13 หลัก

บัตรที่เคยพิมพ์เป็นบาร์โค้ด Code 128 หมายเลข 39 หลักยังค้นในช่องสแกนได้ ควรพิมพ์บัตรใหม่สำหรับเครื่องอ่านแบบเลเซอร์ บัตรไม่แสดงเลขบัตรประชาชน วันเกิด หรือข้อมูลการติดต่อ หมายเลขเริ่มด้วย 2 ใช้ระบุตัวสมาชิกภายในวัดเท่านั้น ไม่ใช่รหัสสินค้าสำหรับค้าปลีก
