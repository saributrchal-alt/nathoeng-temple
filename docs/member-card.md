# บัตรสมาชิกวัด

สมาชิกเปิด **บัญชีของฉัน → บัตรสมาชิกวัด** เพื่อแสดงบัตรบนมือถือหรือกด **พิมพ์บัตร** เจ้าหน้าที่เปิด **Admin → สมาชิก → เลือกสมาชิก → บัตรสมาชิกวัด** แล้วพิมพ์ให้สมาชิกที่ไม่มีมือถือได้ ขนาดพิมพ์ 85.6 × 54 มม.

บัตรแสดงชื่อ รูปโปรไฟล์ หมายเลขสมาชิก และบาร์โค้ด Code 128 ซึ่งเข้ารหัสหมายเลขสมาชิกเดียวกับที่พิมพ์ไว้ใต้บาร์โค้ด หากไม่มีรูปจะแสดงสัญลักษณ์วัด เจ้าหน้าที่ไปที่ **Admin → สมาชิก → สแกนบาร์โค้ดบัตรสมาชิก** กด **เริ่มสแกน** แล้วสแกนได้เลย ระบบค้นหาเมื่อรับเลขครบ 39 หลักหรือเครื่องส่ง Enter จากนั้นกด **เปิดข้อมูลสมาชิก** เพื่อดูโปรไฟล์ หากไม่มีเครื่องสแกนสามารถกรอกเลขใต้บาร์โค้ดและกดค้นหาได้ ช่องนี้แยกจากช่องเลขบัตรประชาชน 13 หลัก

หมายเลขสมาชิกเป็นเลข 39 หลักที่แปลงจาก UUID ของสมาชิกแบบหนึ่งต่อหนึ่ง จึงไม่ซ้ำและไม่เปลี่ยนเมื่อแก้ชื่อหรือรูป บัตรไม่แสดงเลขบัตรประชาชน วันเกิด หรือข้อมูลการติดต่อ ไม่ต้องรัน SQL เพิ่ม
